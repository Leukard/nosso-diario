# 📖 Nosso Diário de Memórias ✨

Um projeto único, imersivo e interativo criado como uma declaração de amor em formato de código. Muito mais que um site, esta é uma cápsula do tempo digital feita para celebrar uma história inesquecível.

## 🌟 O que tem neste diário?

Este projeto foi construído com atenção a cada pequeno detalhe, focado em criar uma experiência mágica e romântica:

*   **Abertura Teatral:** Uma tela de boas-vindas mágica com efeito de "cortina" que desvenda o diário suavemente.
*   **Trilha Sonora Emocionante:** Um mini player flutuante no estilo "vinil mágico" que toca as nossas músicas favoritas, com controles completos de Play/Pause, Avançar/Voltar e Volume.
*   **Contador de Tempo Eterno:** Um cronômetro ao vivo contando cada dia, hora, minuto e segundo desde o dia do "Sim" (26.10.2025).
*   **Galeria de Lembranças:** Fotos estilo Polaroid interativas, fixadas com *washi tape* digital, que deslizam suavemente pela tela.
*   **Máquina de Escrever Oculta:** Uma carta digitada em tempo real na tela assim que a seção é revelada.
*   **A Promessa (Para Sempre):** Um espaço de honra com a citação clássica do filme *Para Sempre*.
*   **Envelope 3D Secreto:** Um botão com selo de cera que, ao ser tocado, abre um envelope 3D realista revelando um segredo flutuante.
*   **Cartão Postal Dinâmico:** Um livro de visitas onde ela pode deixar uma marca eterna. Os recados são enviados diretamente para o e-mail (via Formspree) e salvos no próprio navegador.
*   **O Clímax Interativo:** Um botão de "NÃO" que foge do cursor, garantindo que a única resposta possível seja "SIM". ❤️

## 🛠️ Tecnologias Utilizadas

Este presente foi construído utilizando um ecossistema moderno e veloz:

*   **[React (Vite)](https://vitejs.dev/):** O coração da aplicação, garantindo rapidez e renderização suave.
*   **[Tailwind CSS](https://tailwindcss.com/):** Para todo o design, responsividade e layout encantador.
*   **[Typed.js](https://github.com/mattboldt/typed.js/):** Para o efeito realista da máquina de escrever.
*   **CSS Puro (Keyframes & 3D):** Para a chuva de pétalas flutuantes e toda a engenharia mecânica do Envelope 3D expansível.
*   **[Formspree](https://formspree.io/):** Para a integração silenciosa de e-mail no Cartão Postal.
